AGENT-NATIVE CAPABILITIES

WebMCP Native Tools & Model Context

This web application exposes 11 client-side WebMCP tools via document.modelContext so AI agents can query and control the dashboard directly.

WebMCP Docs
get_situation_summary
Returns whole-country overview: breakdown by severity, worst districts, source health.
list_records
Queries records matching optional source, severity, district or search constraints.
filter_records
Mutates active dashboard filters so person watching sees the exact view requested.
get_record_details
Fetches full raw payload, loss numbers, station coordinates and metadata.
find_critical_gauges
Inspects DHM telemetry for gauges at/above warning or danger thresholds.
find_isolated_settlements
Cross-references road blocks with population demographics cut off.

Nepal Disaster Watch

Nepal Disaster Watch is an independent open-source initiative built for the WebMCP developer ecosystem. It issues no official warnings and sends no legal alerts. It shows what public sources published with their provenance and timestamp attached.
